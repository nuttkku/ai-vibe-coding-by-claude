## 🚦 ส่วนที่ 1: โหมดสิทธิ์ (Permission modes)

**โหมด = กติกาว่า Claude ทำอะไรได้เองโดยไม่ต้องถามเรา** เปรียบเหมือนระดับความไว้ใจที่ให้กับผู้ช่วย

### 1.1 ทั้ง 6 โหมด

| โหมด (ชื่อใน VS Code) | ค่าใน config | Claude ทำได้เองโดยไม่ถาม | เหมาะกับ | ความเสี่ยง |
|---|---|---|---|---|
| 🖐️ **Manual** | `default` | **อ่านไฟล์เท่านั้น** — แก้ไฟล์ / รันคำสั่ง / ใช้เน็ต ต้องถามทุกครั้ง | ผู้เริ่มต้น, งานสำคัญ, โค้ดที่ไม่คุ้น | 🟢 ต่ำสุด (แต่กด Yes บ่อยจนเผลอได้) |
| ✏️ **Edit automatically** | `acceptEdits` | อ่าน + **แก้ไฟล์** + คำสั่งไฟล์พื้นฐาน (`mkdir` `touch` `mv` `cp`) — คำสั่งอื่นยังถาม | แก้โค้ดที่เรากำลัง review อยู่ และ commit ไว้แล้ว | 🟡 ไฟล์ถูกแก้โดยไม่ถาม (ย้อนด้วย git/`/rewind`) |
| 🗺️ **Plan** | `plan` | อ่าน + วางแผน (+ คำสั่งที่ classifier อนุมัติ ถ้ามี Auto) — **ห้ามแก้ไฟล์จนกว่าเราอนุมัติแผน** | ก่อนงานใหญ่ทุกครั้ง, สำรวจโค้ดใหม่ | 🟢 ต่ำ |
| 🤖 **Auto** | `auto` | **ทุกอย่าง** — มีโมเดลอีกตัว (classifier) ตรวจแต่ละ action เบื้องหลังแทนเรา | งานยาว, ลดการกด Yes | 🟠 ปานกลาง — *"ลดการถาม แต่ไม่รับประกันความปลอดภัย"* |
| 🔒 **Don't ask** | `dontAsk` | เฉพาะเครื่องมือที่อยู่ใน allow list — อย่างอื่น **ถูกปฏิเสธทันที** ไม่ถาม | CI / script อัตโนมัติ | 🟢 ต่ำ (ถ้า allow list แคบ) |
| ☠️ **Bypass permissions** | `bypassPermissions` | **ทุกอย่าง ไม่ตรวจอะไรเลย** | เฉพาะใน container/VM ที่พังได้ | 🔴 สูงมาก — ❌ **ห้ามใช้ในหลักสูตร** |

**ข้อเท็จจริงที่ต้องรู้:**
- 🆕 **แผน Pro / Max / Team เริ่มต้นที่โหมด Auto** (ทั้งใน Terminal และ VS Code Extension, Claude Code v2.1.228 ขึ้นไป) — ส่วนแผน Enterprise, API key และ `claude -p` เริ่มที่ Manual
- **กฎ `deny` ใน `.claude/settings.json` บล็อกได้ทุกโหมด** รวมถึง Bypass — จึงเป็นด่านสุดท้ายที่ไว้ใจได้ (เช่น ห้ามอ่าน `.env`)
- Auto mode ใช้ได้เฉพาะโมเดลที่รองรับ (Opus 4.6+, Sonnet 4.6+, Fable) — **ถ้าเลือก Haiku, Auto จะใช้ไม่ได้** และกลับไปเป็น Manual
- Auto mode บล็อกโดยค่าเริ่มต้น เช่น ดาวน์โหลดแล้วรันโค้ด (`curl | bash`), ส่งข้อมูลสำคัญออกไปภายนอก, การลบ path สำคัญ (`rm -rf ~`) และจะ "พยายามทำงานต่อโดยไม่ถามคำถาม" มากขึ้น

### 1.2 วิธีสลับโหมด

| ที่ไหน | วิธี |
|---|---|
| **VS Code Extension** | คลิก **ตัวบอกโหมด** ด้านล่างช่องพิมพ์ → เลือก Manual / Edit automatically / Plan / Auto — Extension **จำโหมดล่าสุดที่เลือก** (Manual, Edit automatically, Auto) ไว้ใช้กับบทสนทนาถัดไป |
| **CLI (Terminal)** | กด `Shift+Tab` วนโหมด: จาก Auto → Manual → Edit → Plan → … แถบสถานะแสดง `⏸ manual mode on`, `⏵⏵ accept edits on`, `⏸ plan mode on`, `⏵⏵ auto mode on` |
| **ตอนเริ่ม** | `claude --permission-mode default` (หรือ `plan`, `acceptEdits`, `auto`) |
| **ตั้งเป็นค่าเริ่มต้น** | VS Code: setting `claudeCode.initialPermissionMode` · CLI: `"permissions": {"defaultMode": "default"}` ใน `~/.claude/settings.json` |

### 1.3 🎓 กติกาโหมดของหลักสูตร

| วัน | โหมดหลัก | เหตุผล |
|---|---|---|
| 1–2 | 🖐️ **Manual** + 🗺️ Plan ก่อนงานใหญ่ | ฝึก **อ่านคำสั่งก่อนกด Yes** — ถ้าเริ่มที่ Auto จะไม่เห็นเลยว่า Claude ทำอะไร |
| 3 | Manual / ✏️ Edit automatically (หลัง commit) | งาน UI, test และแก้ช่องโหว่ — ต้องเห็นทุกการเปลี่ยนแปลง |
| 4 | 🤖 Auto ได้ **เมื่อ**: commit แล้ว + มีกฎ `deny` + ดู `git diff` ก่อน commit ทุกครั้ง | Sprint ต้องการความเร็ว แต่ยังต้องตรวจผล |
| ทุกวัน | ☠️ Bypass | ❌ ห้ามใช้ |

> 💡 **วันที่ 1 ตอนติดตั้ง:** ให้ผู้เรียนทุกคนคลิกตัวบอกโหมดแล้วเลือก **Manual** ก่อนเริ่มแบบฝึก — ไม่งั้นแบบฝึก "กด Yes/No" จะไม่มีอะไรให้กด เพราะ Auto ทำไปเองแล้ว

## 🧠 ส่วนที่ 2: โมเดล (Models)

**โมเดล = "สมอง" ที่ Claude Code ใช้คิด** รุ่นใหญ่ฉลาดกว่าแต่ช้ากว่าและแพงกว่า/กินโควต้ามากกว่า

### 2.1 รุ่นปัจจุบัน

| รุ่น | จุดเด่น | Context | ราคา API (input / output ต่อ 1 ล้าน token) | ใช้เมื่อ |
|---|---|---|---|---|
| ⚡ **Haiku 4.5** | เร็วที่สุด ถูกที่สุด | 200K | $1 / $5 | งานเล็ก ตรงไปตรงมา, subagent ที่ทำงานซ้ำๆ (⚠️ ใช้กับ Auto mode ไม่ได้) |
| 🎯 **Sonnet 5** | สมดุล — เก่งพอสำหรับงานโค้ดประจำวัน | 1M | $2 / $10 | **งานส่วนใหญ่ในหลักสูตร**: scaffold, CRUD, UI, test |
| 🧠 **Opus 5.5** | ฉลาดมาก คิดลึก (ปิดการคิดไม่ได้) | 1M | $4 / $20 | ออกแบบระบบ, บั๊กที่หายาก, งานหลายขั้นตอน — **ค่าเริ่มต้นของ Claude Code บนแผน Pro/Max/Team/API** |
| 🧠 Opus 5 | รุ่นก่อนหน้าของ Opus 5.5 | 1M | $5 / $25 | ยังเลือกได้ด้วยชื่อเต็ม |
| 🏆 **Fable 5.1** | ความสามารถสูงสุดที่เปิดให้ใช้ทั่วไป สำหรับงานยากและยาวที่สุด | 1M | $10 / $50 | งานที่ยากจริงๆ เท่านั้น — บนแผน Pro ใช้ผ่าน **usage credits** (จ่ายเพิ่ม) |

> 💡 **Context window** = ความจำระยะสั้นสูงสุดของ 1 session (1M ≈ 1 ล้าน token ≈ โค้ดหลายหมื่นบรรทัด) — ยิ่งใส่เยอะยิ่งเปลือง ดูได้ด้วย `/context`

### 2.2 ชื่อเล่น (alias) ที่ใช้ใน `/model`

| Alias | ได้รุ่นอะไร (บัญชี Anthropic) |
|---|---|
| `default` | กลับไปใช้ค่าเริ่มต้นของบัญชี (ปัจจุบัน = Opus 5.5) |
| `sonnet` | Sonnet รุ่นล่าสุด (Sonnet 5) |
| `opus` | Opus รุ่นล่าสุด (Opus 5.5) |
| `haiku` | Haiku (Haiku 4.5) |
| `fable` | Fable 5.1 |
| `best` | Fable ถ้าบัญชีใช้ได้ ไม่งั้นเป็น Opus |
| `opusplan` | ⭐ **Opus ตอน Plan mode → สลับเป็น Sonnet ตอนลงมือทำ** — ได้แผนที่ดีแต่ประหยัดตอนเขียนโค้ด |
| `opus[1m]`, `sonnet[1m]` | บังคับ context 1M (Sonnet 5 เป็น 1M อยู่แล้วเสมอ) |

วิธีเปลี่ยน: `/model` (เลือกจากรายการ) · `/model sonnet` · ตอนเริ่ม `claude --model sonnet` · ค่าถาวร `"model": "sonnet"` ใน `~/.claude/settings.json`

### 2.3 ระดับการคิด (Effort) และ Thinking

โมเดลรุ่นใหม่ **"คิดก่อนตอบ"** (extended thinking) — ยิ่งคิดมาก ยิ่งแม่นกับงานยาก แต่ **token ที่ใช้คิดคิดเงินเป็น output token** (ราคาแพงกว่า input 5 เท่า)

| Effort | ใช้เมื่อ |
|---|---|
| `low` | งานสั้น ง่าย ต้องการเร็ว (rename, แก้ typo) |
| `medium` | งานทั่วไปที่อยากประหยัด — **ค่าเริ่มต้นของ Opus 5.5** |
| `high` | สมดุลคุณภาพ/ต้นทุน — ค่าเริ่มต้นของรุ่นอื่นส่วนใหญ่ |
| `xhigh` | คิดลึกขึ้น token มากขึ้น — เหมาะกับงานโค้ดยากๆ |
| `max` | งานที่ยากมาก แต่อาจคิดมากเกินจำเป็น ควรลองก่อนใช้ประจำ |

- ตั้งค่า: `/effort` (มีแถบเลื่อน) หรือ `/effort high` · ตอนเริ่ม `claude --effort high`
- **`ultrathink`** — ใส่คำนี้ใน Prompt เพื่อขอให้คิดลึกเฉพาะข้อความนั้น โดยไม่เปลี่ยนค่า effort ของ session เช่น `ultrathink ทำไม test นี้ fail แค่บางครั้ง`
- เปิด/ปิด thinking: `Alt+T` (Windows/Linux) / `Option+T` (macOS) — ⚠️ Opus 5.5 และ Fable **ปิดไม่ได้**
- ดูว่า Claude คิดอะไร: `Ctrl+O` (verbose mode)
- **`/fast`** — Fast mode: Opus ตอบเร็วขึ้นแต่ราคา **ประมาณ 2 เท่า** และบนแผน Pro/Max คิดจาก usage credits — ❌ ไม่จำเป็นในหลักสูตร

### 2.4 🎓 แนะนำการเลือกโมเดลในหลักสูตร

| สถานการณ์ | โมเดล / effort |
|---|---|
| งานประจำวัน: scaffold, CRUD, UI, test | `sonnet` |
| วางแผน Sprint / ออกแบบ data model | `opusplan` หรือ `opus` + Plan mode |
| บั๊กที่วนแก้ 3 รอบแล้วไม่หาย | `opus` + `ultrathink` (หลัง `/clear` แล้วสรุปปัญหาใหม่) |
| งานเล็ก: rename, commit message, อธิบายโค้ด | `sonnet` + `/effort low` (หรือ `haiku` ถ้าอยู่ใน Manual mode) |
| โควต้าใกล้หมด | `sonnet` + effort `medium` — อย่าใช้ Opus/Fable |

## 💰 ส่วนที่ 3: ค่าใช้จ่าย

### 3.1 หน่วยนับ: Token คืออะไร

**Token = ชิ้นส่วนของข้อความ** ที่โมเดลอ่าน/เขียน — ภาษาอังกฤษ 1 token ≈ 4 ตัวอักษร ≈ ¾ คำ · **ภาษาไทยมักใช้ token มากกว่าภาษาอังกฤษต่อความยาวเท่ากัน** · โมเดลรุ่น 4.7 ขึ้นไปใช้ tokenizer ใหม่ที่นับได้มากกว่าเดิม ~30% สำหรับข้อความเดียวกัน

ใน Claude Code **ทุกข้อความที่ส่ง Claude ต้องอ่านบทสนทนาทั้งหมดซ้ำ** (ประวัติแชท + `CLAUDE.md` + ไฟล์ที่เคยอ่าน + ผลคำสั่ง) — นี่คือเหตุผลที่ `/clear` สำคัญมาก

### 3.2 วิธีจ่ายเงิน 4 แบบ

```
┌───────────────────────┬──────────────────────────────┬────────────────────────────────┐
│ แบบ                   │ จ่ายอย่างไร                    │ เหมาะกับ                        │
├───────────────────────┼──────────────────────────────┼────────────────────────────────┤
│ ① Subscription        │ เหมาจ่ายรายเดือน มีโควต้า         │ ผู้เรียน, นักพัฒนารายบุคคล ✅      │
│ ② Usage credits       │ จ่ายเพิ่มตามจริง เมื่อโควต้า ① หมด  │ วันที่ใช้หนักเกินแผน               │
│ ③ API key (Console)   │ จ่ายตาม token ที่ใช้จริงทุกหน่วย    │ ระบบอัตโนมัติ, CI, องค์กร         │
│ ④ Cloud provider      │ จ่ายผ่านบิล AWS / Google / Azure │ องค์กรที่ใช้ cloud นั้นอยู่แล้ว      │
└───────────────────────┴──────────────────────────────┴────────────────────────────────┘
```

#### ① Subscription (แผนรายเดือน) — ที่หลักสูตรนี้ใช้

| แผน | ราคา | Claude Code | โควต้า | โมเดล |

| Free | $0 | ❌ | พื้นฐาน | Sonnet, Haiku |
| **Pro** | **$20/เดือน** ($17/เดือน ถ้าจ่ายรายปี) | ✅ | อย่างน้อย 5 เท่าของ Free ต่อรอบ 5 ชั่วโมง | Opus, Sonnet, Haiku + Fable ผ่าน usage credits |
| Max 5x | $100/เดือน | ✅ | 5 เท่าของ Pro ต่อรอบ 5 ชั่วโมง | ทุกรุ่นรวม Fable |
| Max 20x | สูงกว่า Max 5x (ดูราคาล่าสุด) | ✅ | 20 เท่าของ Pro | ทุกรุ่นรวม Fable |
| Team (Standard / Premium) | $25 / $125 ต่อคนต่อเดือน ($20 / $100 รายปี) | ✅ | Standard มากกว่า Pro · Premium 5 เท่าของ Standard | — |
| Enterprise | $20/ที่นั่ง/เดือน (รายปี) + ค่าใช้งานตามจริง | ✅ | ตามสัญญา | — |
| Education | ราคาพิเศษสำหรับมหาวิทยาลัย (ติดต่อ Anthropic) | ✅ | — | — |

**โควต้าทำงานอย่างไร:**
- ⏱️ **รอบ 5 ชั่วโมงแบบเลื่อน (rolling)** — ใช้หมดแล้วต้องรอรีเซ็ต · แผนเสียเงินมี **โควต้ารายสัปดาห์** ซ้อนอีกชั้น
- 🔗 **ใช้ร่วมกับ claude.ai** — แชทบนเว็บ/มือถือ กับ Claude Code หักจากโควต้าเดียวกัน
- 🧠 รุ่นใหญ่ (Opus, Fable) และ effort สูง **กินโควต้าเร็วกว่า** · ถ้าขึ้นข้อความ "hit your Opus limit" สลับไป Sonnet ทำงานต่อได้ แต่ถ้า "session limit / weekly limit" ต้องรอ (สลับรุ่นไม่ช่วย)
- 📊 ดูได้ที่ `/usage` ใน Claude Code หรือ claude.ai → Settings → Usage
- 💡 **ตัวเลขเงินใน `/usage` ส่วน Session** เป็นการประเมินตามราคา API — **ไม่ได้เรียกเก็บจริง** สำหรับผู้ใช้ Pro/Max

#### ② Usage credits (จ่ายเพิ่มเมื่อโควต้าหมด)

- เปิดใช้ที่ claude.ai → Settings → Usage (หรือพิมพ์ `/usage-credits` ใน Claude Code)
- คิดเงิน **ตามราคา API** (ตาราง ③) สำหรับส่วนที่เกินโควต้า
- **ตั้งวงเงินต่อเดือน (spend limit) ได้** — ⚠️ แนะนำตั้งทุกครั้ง ถ้าไม่ตั้งจะแสดงเป็น `Unlimited`
- Fable บนแผน Pro และ Fast mode คิดจาก usage credits
- เมื่อใช้ usage credits อายุ cache ลดจาก 1 ชั่วโมงเหลือ 5 นาที (พักนานแล้วกลับมาจะเปลืองขึ้น)

**ค่าใช้จ่ายแต่ละช่องคืออะไร:**

| ประเภท | คืออะไร | ในทางปฏิบัติ |
|---|---|---|
| 📥 **Input** | ข้อความที่ส่งให้โมเดลอ่าน: Prompt, ประวัติแชท, `CLAUDE.md`, โค้ดที่อ่าน, ผลคำสั่ง | ใน Claude Code เป็นก้อนใหญ่ที่สุด เพราะส่งประวัติซ้ำทุกรอบ |
| 📤 **Output** | ข้อความที่โมเดลเขียน **รวม token ที่ใช้คิด (thinking)** | แพงกว่า input 5 เท่า — effort สูง = output มาก |
| 💾 **Cache write** | ครั้งแรกที่ส่งข้อความชุดหนึ่ง ระบบจดจำไว้ (แพงกว่า input ปกติ 1.25 เท่า สำหรับ 5 นาที หรือ 2 เท่า สำหรับ 1 ชั่วโมง) | Claude Code ทำให้อัตโนมัติ |
| ⚡ **Cache read** | ครั้งต่อๆ ไปที่ส่งข้อความชุดเดิม อ่านจาก cache (ถูกกว่า input ปกติ **10 เท่า** — Opus 5.5 ถูกกว่า 20 เท่า, Fable 5.1 ถูกกว่า 40 เท่า) | เหตุผลที่บทสนทนาต่อเนื่องไม่แพงเท่าที่คิด — **แต่พักนานเกินอายุ cache แล้วกลับมา = อ่านใหม่ราคาเต็ม** |
| 📦 **Batch** | ส่งงานเป็นชุดแบบไม่ต้องรอผล ลด 50% | ใช้กับโปรแกรมที่เรียก API — ไม่ใช้กับ Claude Code แบบโต้ตอบ |
| 🏎️ **Fast mode** | Opus เร็วขึ้น ราคาพิเศษ (Opus 5.5: $8 / $40) | ไม่จำเป็นในหลักสูตร |
| 🌏 **Data residency** | บังคับประมวลผลในสหรัฐฯ (`inference_geo: "us"`) เพิ่ม 1.1 เท่า | ใช้กับงานที่มีข้อกำหนดเรื่องที่เก็บข้อมูล |
| 🔎 **Web search** | ค้นเว็บ $10 ต่อ 1,000 ครั้ง + ค่า token ของผลค้นหา | web fetch (เปิดหน้าเว็บ) ไม่มีค่าเพิ่มนอกจาก token |

**ตัวอย่างคำนวณ (สมมติ):** งานแก้บั๊ก 1 ชิ้นใน Claude Code — Claude ส่ง request 30 ครั้ง แต่ละครั้งแบกบริบท ~40,000 token (รวม input 1.2 ล้าน token โดย 90% อ่านจาก cache), เขียน cache ใหม่ 100,000 token, output (รวม thinking) 20,000 token

| รุ่น | Input ไม่ติด cache (120K) | Cache read (1.08M) | Cache write (100K) | Output (20K) | **รวม** |
|---|---|---|---|---|---|
| Haiku 4.5 | $0.12 | $0.11 | $0.13 | $0.10 | **≈ $0.45** |
| Sonnet 5 | $0.24 | $0.22 | $0.25 | $0.20 | **≈ $0.91** |
| Opus 5.5 | $0.48 | $0.22 | $0.50 | $0.40 | **≈ $1.60** |
| Fable 5.1 | $1.20 | $0.27 | $1.25 | $1.00 | **≈ $3.72** |

💡 ถ้า **ไม่มี cache** งานเดียวกันบน Sonnet 5 จะเป็น 1.2M × $2 + $0.20 ≈ **$2.60** (แพงขึ้นเกือบ 3 เท่า) — นี่คือเหตุผลที่ห้ามพักบทสนทนายาวไว้นานแล้วกลับมาถามต่อ ควร `/clear` เริ่มใหม่

อ้างอิงขนาดจริง: Anthropic รายงานว่าองค์กรที่ใช้ Claude Code แบบจ่ายตาม API เฉลี่ย **~$13 ต่อนักพัฒนาต่อวันทำงาน** หรือ **$150–250 ต่อคนต่อเดือน** (90% ของผู้ใช้ไม่เกิน $30/วัน)

#### ④ Cloud provider (Amazon Bedrock, Google Cloud, Microsoft Foundry)

องค์กรที่ใช้ cloud เหล่านี้อยู่แล้วเรียก Claude ผ่าน cloud ได้ บิลมาทาง cloud — ราคาของ Bedrock / Google Cloud กำหนดโดยผู้ให้บริการ (Foundry คิดราคาเดียวกับ API) — ไม่เกี่ยวกับหลักสูตรนี้
