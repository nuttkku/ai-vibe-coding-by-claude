# 🎮 Claude Playground

โฟลเดอร์ฝึกสำหรับ **Claude Code Bootcamp** และ **Git Bootcamp** วันที่ 2

- `calc.js` — ฟังก์ชันคำนวณยอดขาย มี **บั๊กจงใจ 3 จุด**
- `calc.test.js` — test ที่จะผ่านเมื่อแก้บั๊กครบ (รันด้วย `npm test` ไม่ต้อง `npm install`)
- `.env.example` — ค่าปลอม ใช้ทดสอบว่า Claude อ่าน `.env` ไม่ได้

⚠️ **คัดลอกโฟลเดอร์นี้ออกไปไว้นอก repo หลักสูตรก่อนเริ่ม** (เช่น `~/vibe-playground`) เพราะภารกิจ Git จะ `git init` ในโฟลเดอร์นี้

ภารกิจทั้งหมดอยู่ใน [บทเรียนวันที่ 2](../../README.md#-1-claude-code-bootcamp)
